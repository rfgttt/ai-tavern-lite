## 3. 后端测试范围

### 角色与兼容性

- Character Card V2/V3 与 PNG 导入；
- 中文角色名和模板变量；
- 角色创建、编辑、删除、导出；
- 未知扩展字段保留；
- 严格 CCv3 导出与再导入；
- 主开场白、备用开场白、排序、空值和重复校验；
- 世界书常驻、关键词、禁用和概率字段；
- 兼容性报告和 Tavern Helper 安全子集。

### 会话、聊天与运行时

- 单人、Persona、编组和新会话选项；
- 主角色必须属于选定编组；
- 用户消息只向 Provider 发送一次；
- SSE `message`、`done` 和 `error`；
- 停止生成与取消竞态；
- 重新生成与失败保护；
- 消息状态、序号和会话活跃时间；
- 运行时状态补丁、时间线和回滚；
- 删除消息后的状态恢复；
- 骰子、战斗和 MVU/JSONPatch 安全解析；
- 部分状态不能在停止生成后误应用。

### ChatOrchestrator

- 配置不完整返回 422，且不写入待生成消息；
- 不安全 Base URL 返回 422；
- Provider 意外初始化失败返回 503；
- Provider 流错误后活动任务注册表清理；
- 首个事件后断开会把消息保存为 `stopped`。

### 数据与迁移

- 空数据库通过 Alembic 创建完整结构；
- 现有无版本数据库无损接管；
- 已知旧字段与消息序号修复；
- SQLAlchemy metadata 与迁移结果无漂移；
- 强制迁移失败后恢复备份；
- 删除角色、会话后的级联完整性；
- 上传大小限制和 Prompt 预算；
- 1002 条消息完整且序号连续。

### 安全与诊断

- SSRF 拒绝本机和内网目标；
- 允许显式公网目标；
- Basic Auth 保护与健康检查豁免；
- JSON 请求体限制；
- API 速率限制；
- 生产配置无认证时 fail-closed；
- API Key 不泄漏；
- 诊断数据和导出包脱敏；
- 诊断成功、停止和失败状态记录；
- 自检结果与 ZIP 导出。

- 浏览器已验证 1002 条消息的后端完整性，但尚未加入虚拟列表；
- 公网部署、反向代理、证书、故障注入和长时间稳定性尚未作为当前阶段门禁；
- SQLite 多实例写入不在支持范围；
